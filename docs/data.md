# Data sources

Every dataset used in this project is listed here with its URL, license and the date it
was obtained. Synthetic data is marked as synthetic. No real personal data is used.

Rule: no website is scraped or bulk-downloaded until its terms of use have been read and
the result is recorded in this file (who checked, when, what the terms allow).

## In use

| ID | Description | URL | License | Obtained | Synthetic | Used for |
|---|---|---|---|---|---|---|
| `synthetic-contracts-v1` | Template-generated contracts (uz-Latn, uz-Cyrl, ru) as text PDF, DOCX and simulated scans. Parties, names, amounts and addresses are invented. | generated by `scripts/make_synthetic_docs.py` (this repo) | MIT (same as the code) | generated on demand (seeded, deterministic) | **yes** | ingestion tests, OCR error rate measurement |
