# Data sources

Every dataset used in this project is listed here with its URL, license and the date it
was obtained. Synthetic data is marked as synthetic. No real personal data is used.

Rule: no website is scraped or bulk-downloaded until its terms of use have been read and
the result is recorded in this file (who checked, when, what the terms allow).

Two kinds of data, always reported separately:

- **Real documents** (laws, official model contracts): the **main evaluation set**.
- **Synthetic documents**: used for OCR and file-format tests only (plus a clearly
  labeled synthetic retrieval sanity check). Never mixed into the real results.

### Notes on `synthetic-contracts-v1`

- Marked synthetic in the text (first line "SINTETIK NAMUNA" / "СИНТЕТИЧЕСКИЙ ОБРАЗЕЦ"),
  in file names (`syn-` prefix), in PDF/DOCX metadata, in `manifest.jsonl`
  (`"synthetic": true`) and in the database (`documents.is_synthetic`).
- uz-Cyrl documents are **machine-transliterated** from the uz-Latn templates
  (`documind/translit.py`), not written by a native Cyrillic writer.
- Templates were written for this project (`scripts/synthetic_templates.py`); legal wording
  is illustrative and not legal advice.
- Simulated scans: 200 dpi rendering, skew within ±0.8°, light blur, noise and JPEG
  compression. This is cleaner than many real scans (no stamps, signatures, folds,
  handwriting, low-contrast copies), so OCR results on it are optimistic.
- Generated files are not committed (`data/synthetic/` is git-ignored); the split is
  frozen in `data/splits.json`.
